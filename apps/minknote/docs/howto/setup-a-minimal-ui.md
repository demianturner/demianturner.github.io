Many writers prefer minimal clutter in their app setup. Take the following steps to reduce user interface distraction.

## Hide Toolbar Titles

Choose Icon Only:

![](/apps/minknote/docs/images/howto/CleanShot_2025-12-30_at_11.07.36%402x.png)

## Hide the Sidebar and Note List

View only your note with `⌘1 `. `⌘2 ` and `⌘3 ` turn on the Note List and Sidebar, respectively.
