## Modern Rich Text Editor

* **Dual Mode Editing**: Seamless WYSIWYG and Markdown modes in one integrated editor
* **Command-E Toggle**: Instant switching between WYSIWYG and Markdown modes with keyboard shortcut
* **GitHub-Flavored Markdown**: Full support for GFM syntax including task lists, tables, and strikethrough
* **Frontmatter Management**: YAML Frontmatter used to handle note meta data
* **Live Preview**: Real-time rendering of markdown content
* **Syntax Highlighting**: Clear visualization of Markdown syntax
* **Auto-Linking**: Optional auto-linking of plain URLs
* **Code Support**: Render inline code and code blocks
* **Overscroll Support:** Keep the current line comfortably centred while writing long documents

## Advanced Image Handling

* **Drag & Drop Support**: Drag images from Finder directly into notes
* **Paste Support**: Copy/paste images from clipboard
* **Organized Storage**: Images stored in sibling `i/` folders (e.g., `/Notes/i/image.png`)
* **Image Relocation**: Moving notes automatically relocates associated images
* **Duplicate Handling**: Smart filename resolution when images conflict

## Multiple Project Support

* **Independent Workspaces**: Organize different groups of journals and notes in separate projects anywhere on your Mac
* **Easy Switching**: Change project location anytime via Preferences → Projects → "Switch Project"
* **Use Cases**: Keep personal journals separate from work notes, organize projects by client or topic, maintain multiple independent knowledge bases

## Local Storage

* Direct filesystem manipulation for external tool compatibility
* Hierarchical organization (Journals → Folders → Sub-folders → Notes)
* Standard markdown file formats (.md, .txt, .markdown)

## Cloud Sync

* Simply place your files and folders in an iCloud Drive folder or any other cloud provider to sync to your other devices
* Works with Dropbox, Google Drive, OneDrive, or any cloud storage service
* No built-in sync required - use your preferred cloud solution

## AI Integration

* Integrated with Apple's Writing Tools
* Select text and right click

## Hierarchical Folder Structure

* **3-Level Deep Nesting**: Journals → Folders → Sub-folders (up to 3 levels)
* **Context Menus**: Right-click to delete folders, journals, and notes

## Note Moving & Organization

* **Drag & Drop Notes**: Drag notes between journals and folders in sidebar
* **Image Migration**: Associated images automatically move with notes
* **Duplicate Resolution**: Smart handling of duplicate image filenames with "copy N" suffixes

## Dark Mode Support

* Automatic detection of system appearance (light/dark mode)
* Or set the app's dark mode independently of your system settings

## Keyboard-First Navigation

* **Full Shortcut Support**: Create notes, switch layouts, search, save, tag, and toggle favourites from the keyboard
* **Fast Focus Movement**: Move between journals, notes, and the editor without reaching for the mouse
* **Native Mac Feel**: Deep menu bar and keyboard integration across the app

## Flexible Layouts & Windows

* **One, Two, or Three Panes**: Switch between focused writing, notes + editor, or full library layouts instantly
* **Detached Note Windows**: Open a note in its own window for side-by-side work or a distraction-free editing view

## Triple Search System

### Global Search (⌘⇧F)

* Comprehensive search across **all journals and folders**
* Searches note titles, content, tags, and authors
* Keyboard navigation: arrow keys to select, return to open

### Filter Notes (⌘⌥F)

* Fast filtering within current journal/folder
* Instant results as you type
* Searches titles and content

### Find In Current Note (⌘F)

* Search the contents of the selected note

## Browse Notes By Tag

* Click any tag in the sidebar Tags section to filter the note list and show all notes with that tag across all journals.
* Manage tags per note, with auto-suggest

## Favourites

* **Quick Access**: Mark important notes as favourites and open them from a dedicated sidebar view
* **Library-Wide View**: Favourites work across journals and folders, so key notes stay easy to find

## Frontmatter Support

* Full YAML metadata support in markdown files
* Tags, authors, creation and modification dates
* Custom metadata fields supported

## Preferences & Customization

* The app's UI is highly customisable to suit your preferences

## Auto-save & Persistence

* Define whether you'd like your edits saved automatically or manually

## Web Export

* Copy/paste web pages into the WYSIWYG view and content is converted into Markdown, great for saving web content
