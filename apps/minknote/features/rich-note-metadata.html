Note Context

Rich Note Metadata

Every note can carry useful context alongside your writing. MinkNote records details such as creation time, device, tags and other note information directly in the Markdown file, with more context such as location and weather planned for the future.

All features

MinkNote keeps useful context about your notes alongside the writing itself. This can include when a note was created, the device it came from, its tags, favourites and other details that help describe and organise it.

In the future, this can grow to include richer context such as location and weather, making journal entries and notes more meaningful when you return to them later.

All of this information stays with the Markdown file itself. Move it, back it up or open it somewhere else, and that context moves with it. Your notes remain portable, readable and fully yours.
