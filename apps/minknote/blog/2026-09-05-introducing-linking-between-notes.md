MinkNote 1.4 adds note linking. You can connect a phrase in one note to another note in the same project, then jump there whenever you need the rest of the picture.

Some ideas belong together even when they live in different notes. A meeting note can point to a plan. A reading note can send you back to a journal entry. The link sits in the writing itself.

## Adding a link

Select the text you want to turn into a link, then right-click and choose **Add Link**, or use the internal-link button in the formatting toolbar. You can also press **Command-K** while the editor has focus.

If text is selected, MinkNote uses it as the link name. If nothing is selected, Command-K opens the window with **Use Note Title** on and inserts the link at the cursor. Command-K only works when the note editor has focus.

## Finding the destination

Type in **Search entries** to find a note. MinkNote searches the current project by title, body text, or tags. Move through the results with the mouse or the arrow keys, then press **Return** to choose a note. **Escape** closes the window without changing anything.

## Naming the link

The link name is the text that appears in your note. Leave **Use Note Title** off to keep what you selected, or turn it on to use the destination note's title. The note itself only changes when you click **OK**.

## Copying and following links

Right-click a note in the list and choose **Copy Link To Note** to copy that note's link. You can paste it into another note, a message, or another app. Opening it takes you to the note in MinkNote.

Click an internal link to open the destination in a new window. You do not need to find the journal or folder first. If the note cannot be found in the current project, MinkNote leaves the link in place and shows a not-found message. External web links still use the regular link tool.

Links continue to work if the destination note is renamed or moved.

The [Linking Notes](/apps/minknote/docs/editing-and-formatting/linking-notes/) guide has the full walkthrough of the Add Link window.
